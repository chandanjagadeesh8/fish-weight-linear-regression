## About

This project uses multiple linear regression to predict fish weight based on physical measurements.

## Features

- Length3
- Height
- Width

## Target

- Weight

## Model

Multiple Linear Regression using Python and Scikit-learn.

## Model Evaluation

- R² Score: 0.82
- MAE: 110.84
- MSE: 20202.12

## Example Prediction

- Length3 = 34.6
- Height = 12.88
- Width = 5.556

Predicted Weight:

- 547.98
